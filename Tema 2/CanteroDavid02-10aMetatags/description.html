2. Meta Description

La meta description es una etiqueta que ofrece un resumen del contenido de una página web.

Importancia para el SEO

Google puede utilizarla como descripción en los resultados de búsqueda. Una descripción atractiva puede animar a los usuarios a entrar en la página, aunque no es un factor directo de posicionamiento.

Ejemplo

<meta name="description" content="Descripción de mi página web.">
