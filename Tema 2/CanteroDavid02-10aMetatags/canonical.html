10. Canonical

La etiqueta canonical es un elemento link que indica a los buscadores cuál es la URL preferida cuando existen páginas duplicadas o muy similares.

Importancia para el SEO

Ayuda a consolidar señales de páginas similares y a indicar qué URL se desea priorizar. No garantiza que el buscador elija esa URL.

Ejemplo

<link rel="canonical" href="https://www.ejemplo.com/pagina/">

La dirección de ejemplo debe sustituirse por la URL canónica real. Canonical no es una etiqueta meta.
