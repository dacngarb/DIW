8. Meta Keywords

La etiqueta meta keywords se utilizaba para indicar palabras clave relacionadas con el contenido de una página.

Importancia para el SEO

Google no utiliza la etiqueta meta keywords para posicionar páginas web. Por eso, actualmente no es necesario incluirla para mejorar el SEO.

Ejemplo

<meta name="keywords" content="HTML, SEO, páginas web">
